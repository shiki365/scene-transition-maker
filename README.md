# 場面転換素材メーカー

暗転・ワイプ・アイリスといった「場面転換」のアニメーション素材（APNG）を作るツールです。
背景が透過したまま動くので、TRPG のオンラインセッションツールで画面の上から被せる使い方を想定しています。

使い方は 2 通りあります。

| | 用途 |
| --- | --- |
| **ブラウザ版**（`docs/`） | 設定を変えながら 1 枚ずつ作る。インターネットに公開できるのはこちら |
| **デスクトップ版**（Python） | 18 種類をまとめて作る、コマンドで細かく指定する |

どちらも同じ効果を作ります（後述の検証で、18 種類中 16 種類がピクセル単位で一致することを確認済み）。

## ブラウザ版

`ブラウザで作る.bat` をダブルクリックすると `docs/index.html` が既定のブラウザで開きます。
サーバーは不要で、ファイルを直接開くだけで動きます。処理はすべてブラウザの中で完結し、画像がどこかに送られることはありません。

```
docs/
├── index.html     画面とスタイル
├── app.v1.js      効果の計算とプレビュー
└── apng.v1.js     APNG の書き出し
```

外部ライブラリは使っていません。圧縮はブラウザ標準の `CompressionStream` を使うので、読み込むファイルは 3 つだけです。

## インターネットに公開する

`docs/` フォルダをそのまま置けば公開できます。**GitHub Pages が一番手数が少ない**です。

1. GitHub でリポジトリを作り、このフォルダを push する
2. リポジトリの Settings → Pages を開く
3. Source を「Deploy from a branch」、ブランチを `main`、フォルダを **`/docs`** にして Save
4. 1〜2 分で `https://<ユーザー名>.github.io/<リポジトリ名>/` が公開される

GitHub を使わない場合は、[Cloudflare Pages](https://pages.cloudflare.com/) や [Netlify](https://app.netlify.com/drop) に `docs` フォルダをドラッグするだけでも公開できます。

公開前に **`LICENSE` の著作権者名**（`<あなたの名前 …>` の部分）を書き換えてください。

### 公開後に直すとき

ファイルを差し替えて push し直すだけです。URL は変わりません。デプロイ履歴が残るので、おかしくなったら前の版に戻せます。

ひとつだけ注意が要るのが**キャッシュ**です。「直したのに古い画面が出る」を避けるため、
JavaScript を変更したときは**ファイル名の番号を上げて**ください。

1. `app.v1.js` を `app.v2.js` にリネーム
2. `index.html` の `<script src="app.v1.js">` を `app.v2.js` に変更
3. ページ下部の `v1 ・ 最終更新 …` の表記も更新

こうすると、訪問者のブラウザが古いファイルを掴んだままになることがありません。
HTML そのものは数分〜10 分ほどキャッシュされることがあるので、直後の確認は `Ctrl+F5` で強制再読み込みしてください。

## デスクトップ版

`素材をつくる.bat` をダブルクリックすると、18 種類を既定の設定でまとめて作り、`out` フォルダに出力します。
一覧で見比べられる `out/preview.html` も一緒に作られます。

`コマンドで細かく作る.bat` からはコマンドで指定できます。

```powershell
python make_transition.py list                     # プリセット一覧
python make_transition.py make fade-out            # 1 つ作る
python make_transition.py all --open               # 全部作ってプレビューを開く
python make_transition.py make caption --text "翌朝" --size 1920x1080
python make_transition.py make --help              # 使えるオプション全部
```

ブラウザ版にはない `--fps` `--seed` `--font`、アニメーション WebP 出力（`--format webp`）も使えます。

`.venv` は作成済みです。壊れたときだけ `py -m venv .venv` と
`.\.venv\Scripts\python.exe -m pip install -r requirements.txt` を実行してください。

## プリセット

| 名前 | 効果 | 終わり方 |
| --- | --- | --- |
| `fade-out` | 暗転（黒でフェードアウト） | 黒のまま残る |
| `fade-in` | 明転（黒から明ける） | 透明になって消える |
| `white-out` | ホワイトアウト | 白のまま残る |
| `white-in` | ホワイトイン | 透明 |
| `flash` | 一瞬白く光る（回想・衝撃の合図） | 透明 |
| `wipe-right` | 左から右へ黒が覆う | 黒 |
| `wipe-open-right` | 黒が右へ抜けて画面が現れる | 透明 |
| `wipe-down` | 上から下へ黒が覆う | 黒 |
| `diagonal-wipe` | 左上から右下へ覆う | 黒 |
| `curtain-close` | 暗幕が上下から閉じる | 黒 |
| `curtain-open` | 暗幕が中央から上下へ開く | 透明 |
| `iris-out` | 円が絞られて閉じる | 黒 |
| `iris-in` | 円が開いて画面が現れる | 透明 |
| `blinds` | 横帯が伸びて覆う | 黒 |
| `dissolve` | 砂状に溶けて覆う | 黒 |
| `mosaic` | 四角いブロックが埋まって覆う | 黒 |
| `band-sweep` | 黒帯が左から右へ通過する | 透明 |
| `caption` | 暗転してテロップを表示 | 黒＋文字 |

「黒のまま残る」系は場面を隠す側、「透明」系は新しい場面を見せる側です。
`fade-out` → 場面差し替え → `fade-in` のように 2 枚 1 組で使うと自然につながります。

## 使うときのメモ

- **拡張子は `.png`** です。中身は APNG で、ブラウザは拡張子ではなくファイルの中身を見て再生するため、そのままアップロードしてアニメーションします。
- **1 回だけ再生**が既定です。再生し終わると最後のフレームで止まるので、暗転系は黒いまま画面を隠し続けます。
- 画面いっぱいに広げて使う想定のサイズです。ベタ塗り中心の効果は小さいサイズでも見た目がほぼ変わらないので、640 × 360 にするとファイルがかなり軽くなります。
- `dissolve` は粒がランダムなぶん圧縮が効かず重くなります。粒を大きくすると軽くなります。

## 仕組み

効果ごとに専用の描画をせず、**進行フィールド**という 1 枚のグレースケール画像に集約しています。
フィールドの画素値は「その画素がいつ塗られるか」（0 = 最初、255 = 最後）を表し、
横グラデーションならワイプ、同心円ならアイリス、ランダムノイズならディゾルブになります。
あとはフレームごとにフィールドへルックアップテーブルを当てるだけで全効果が作れます。

この構造のおかげで、Python 版とブラウザ版が同じ計算をしていることを機械的に確かめられます。
両方で全プリセットを出力してフレームごとに突き合わせた結果:

- 18 種類すべてでコマ数が一致
- 16 種類はアルファ値まで完全一致（差 0）
- 残る `dissolve` と `mosaic` は乱数の実装差で粒の模様のみ異なる（動きは同じ）

ブラウザ版のファイルサイズは Python 版より 5〜10% 大きくなります。ブラウザの圧縮設定を細かく指定できないためで、
中身の絵は同じです。
